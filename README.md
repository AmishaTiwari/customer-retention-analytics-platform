# Customer Retention Analytics Platform

> **Status:** Scaffolding only (Commit 1 of 12). This is a placeholder.

A production-oriented Applied Machine Learning platform for predicting
voluntary customer churn, built as a portfolio demonstration of
end-to-end ML engineering practices rather than benchmark performance.

## Current state

The repository structure, package skeleton, dependency manifest, and
configuration skeleton are in place. No pipeline stage is functional
yet — module files under `src/retention_platform/` are documented stubs.
`make reproduce` will not yet produce a working pipeline.

See `docs/adr/` for implementation decisions made so far.
